1. Executive Overview & System Topology

FundedShift operates as an institutional proprietary trading firm platform. It provides simulated capital evaluation challenges for traders globally, validates risk discipline through real-time telemetry, and automates high-water mark profit distributions.

Layer 1: Presentation & Trader Workspace (React 19, TypeScript, Tailwind CSS, Vite)

Includes the institutional Trading Terminal with TradingView live candlestick charts, live 200ms market watch, lot size sizing calculator, position monitor, Trader Portal (Objectives, Invoices, Certificates, KYC verification, Payout desk, Support desk), and Admin Control Suite.

Layer 2: API Gateway & Security Firewall (Express 4.21, Node.js 22 LTS)

Handles dual-bearer JWT & header authentication, RBAC authorization (Trader vs Admin), IP-based rate limiting (Auth: 40/15min, Orders: 60/min, Checkout: 20/min), payload sanitation, and audit trail dispatch.

Layer 3: Core Financial & Simulated Trading Engines

Simulated ECN Execution Engine: Sub-millisecond order matching, variable bid/ask spread modeling, slippage simulation, and margin reservation.
Dynamic Risk Shield: Asynchronous 200ms tick evaluation of intraday drawdown (5%) and maximum drawdown (10%), triggering instant position flattening.
Automated Transition Engine: Automated Step 1 → Step 2 → Funded account provisioning upon target achievement.
Payout & Split Engine: Real-time profit split accounting (80% / 90%) and multi-channel disbursement.

Layer 4: Relational Persistence Layer (PostgreSQL 16 Engine)

16 ACID-compliant relational tables managed with foreign key constraints, cascading updates, synchronous snapshot synchronization to disk, and audit logging.

Automated Account Provisioning & Transition Engine

Upon achieving the profit target in Phase 1, all active trades are automatically closed to lock gains. The account status switches to PASSED. An automated background worker provisions the Step 2 Verification account within 1 to 2 hours with fresh MT5 credentials. When Step 2 is cleared, the system awards the official prop firm certificate and transitions the trader to the live funded desk.

3. Simulated MT5 Execution Engine & Financial Mathematics

The execution engine replicates high-liquidity MT5 / cTrader environments with realistic market conditions.

Market Ticker & Spread Model

Generates realistic price vibrations every 200 milliseconds across Forex Majors, Crosses, Commodities (XAUUSD, XAGUSD), Indices (NAS100, US30), and Cryptocurrencies (BTCUSD, ETHUSD). Spreads dynamically widen during high volatility or session transitions.

Order Fill & Slippage Simulator

Simulates ECN depth-of-market fills. Large lot sizes incur realistic micro-slippage (0.1 - 0.5 pips). Validates weekend closures, maximum open position counts, and per-symbol maximum lot limits.

Mathematical Formulations in Code

1. Floating Unrealized PnL:
BUY: PnL = (Current Bid Price - Entry Price) × Lot Size × Contract Size
SELL: PnL = (Entry Price - Current Ask Price) × Lot Size × Contract Size
2. Required Margin:
Margin = (Lot Size × Contract Size × Entry Price) / Account Leverage
Free Margin = Max(0, Live Equity - Used Margin)
Margin Level % = (Live Equity / Used Margin) × 100
3. Live Equity:
Live Equity = Current Balance + ∑(Open Positions Floating PnL)

4. Dynamic Risk Shield & Rule Enforcement

The proprietary risk monitor safeguards firm capital by enforcing strict drawdown limits in real time.

Rule 1

Daily Loss Limit (5%)

At 00:00 UTC daily, the baseline is captured:
start_of_day_baseline = Max(balance, equity)
If Live Equity < (start_of_day_baseline - 5%), the account is instantly breached. Floating losses count towards the limit.

Rule 2

Maximum Overall Drawdown (10%)

Static Model: Floor remains at starting balance minus 10% permanently.
Trailing Model (Instant Funding): Floor trails the highest achieved equity until it reaches starting balance, locking in risk.

Emergency Flattener Execution Protocol

Upon breach detection, the risk engine executes within 50ms:
1. Liquidate: Automatically flattens all open positions across all asset classes.
2. Lock: Sets account.status = "BREACHED", blocking all future order requests.
3. Audit: Writes a complete rule_violations entity recording triggering price, equity, and timestamp.
4. Notify: Sends an instant in-app notification explaining the breach specifics.
5. Recovery: Activates the Account Recovery Program with discounted reset pricing (20% to 50% discount).

6. Financial Operations, KYC & Payout Processing

Comprehensive financial compliance and profit disbursement architecture.

Compliance

KYC Verification Pipeline

1. Trader submits legal identity document (Passport, Driver's License, or National ID) under /dashboard/security.
2. Record enters kyc_submissions with status PENDING.
3. Administrator reviews document in /admin/kyc against sanctions/PEP lists.
4. Once approved, user.is_verified is set to true, unlocking automated profit split payout requests.

Accounting

Profit Split & Payout Rails

Eligibility: Only verified funded accounts with profit > 0 and no open positions.
Formula: Trader Payout = Profit × (Trader Split % / 100) (Standard 80%, Scaled 90%).
Disbursement Rails: Crypto USDT (TRC-20, ERC-20), Bank Wire, UPI (India), and PayPal.
SLA: Processed and dispatched within 4 hours.

7. Support Desk, Admin Operations & Security

Enterprise administrative suite and support ticketing infrastructure.

Real-Time Support Helpdesk

Trader Portal (/dashboard/support): Interactive ticket creation with categories (Trading & Rules, Billing, Verification, Payouts, Technical, General) and message conversation threads.
Admin Console (/admin/support): Split-pane management workspace with queue search, status filters (Open, In Progress, Resolved), and instant reply dispatcher with trader alerts.

Security & Infrastructure Safeguards

Password Protection: PBKDF2 with SHA-512 and salt (1,000 rounds).
Authentication: Cryptographically signed JWT tokens with role expiration.
Anti-Fraud: Nonce verification on payment webhooks and rate limiting.
Zero Mock Policy: Decoupled from fake starter accounts; clean empty states for new traders.
